# Course Registration System

## 📌 Overview

This project is a web application that allows users to register, view, and manage courses. It is built using Spring Boot for the backend and basic frontend 
technologies like HTML, CSS, and JavaScript.

---

## 🚀 Features

* Add new courses
* View all available courses
* Register for a course
* Update course details
* Delete courses
* Search courses (optional)

---

## 🛠️ Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL / PostgreSQL
---
## ▶️ How to Run the Project

1. Clone the repository
2. Open the backend project in your IDE
3. Configure database in `application.properties`
4. Run the Spring Boot application
5. Open frontend files in browser
---

## 🧠 How It Works
* Requests are sent to the backend using APIs
* Backend processes the request and stores/retrieves data from the database
* Response is sent back to the Postman and displayed to the user
